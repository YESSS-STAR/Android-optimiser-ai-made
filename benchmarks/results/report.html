Measurement overhead

Per-invocation cost is dominated by interpreter startup in the simulator, not by the shell. Real adb is a native binary. Measured on this machine: 547.6 ms per invocation with an argument vector, 552.9 ms through a host shell — a difference of 5.3 ms. The simulated adb is a Python program, so interpreter startup dominates both figures. Real adb is a native binary.

Legacy FPS diagnostic

The original's SurfaceFlinger check sleeps 4.8 s unconditionally (0.4s sleep per line x 12 lines, hard-coded, regardless of device speed), giving a wall-clock of 6.52 s for 3 round-trips. This project has no equivalent: it does not pad its runtime with fixed sleeps.

Failure reporting

Every device command in the fault set is made to fail. What matters is not whether the tool survives, but whether it tells the truth about what happened.

BehaviourOriginalThis project

run_cmd() returns e.stderr on failure; the caller prints it under a '-> Disabled <pkg>:' label and never checks it

The two sides are given different numbers of faults (3 vs 8) and this is inherent, not an artefact: the fault set covers 8 packages, but the legacy matcher only ever targets 11 packages, of which just 3 are in the fault set. It never touches the other 5, so it cannot be observed failing on them. The comparable figure is the detection rate, which is normalised by the number of faults each side was actually given.

The baseline is the original script copied byte for byte and imported at runtime, so the comparison measures the real code rather than a paraphrase of it. The simulated device is a full adb CLI emulation backed by a state file, which makes every figure deterministic and reproducible with python benchmarks/run_all.py.

Round-trips are the primary metric because they are exact, deterministic and platform-independent. Wall-clock figures are reported too, but they carry a harness overhead — see the note under End to end — and should be read as ratios, not absolutes.

Every figure above is produced by python benchmarks/run_all.py and written to benchmarks/results/benchmarks.json.
